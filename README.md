<h1 align="left">Discord Bot</h1>
ainda em fase de teste, sujeito a futuras atualizações

###

<p align="left">Este projeto consiste no desenvolvimento de um bot para Discord utilizando Node.js e a biblioteca discord.js.<br>A ideia é que o bot ajude a automatizar tarefas no servidor, oferecendo várias funcionalidades, como responder a comandos específicos, interagir com os membros e ajudar na organização das atividades da comunidade.</p>

###

<h3 align="left">Configurando Bot na API do Discord</h3>

###

<p align="left">1.Clone o repositório para a sua máquina local usando git clone:<br><br>Execute o comando git clone <URL_DO_REPOSITÓRIO> no terminal para clonar o repositório do bot de Discord para o seu computador.<br>2.Instale as dependências do projeto:<br><br>Navegue até a pasta do projeto clonado usando cd <NOME_DA_PASTA>.<br>Execute npm install no terminal para instalar todas as dependências necessárias do Node.js listadas no package.json.<br>3.Inicie o bot usando o comando node index.js:<br><br>No terminal, estando na pasta do projeto, execute node index.js para iniciar o bot. O bot deve estar online no seu servidor do Discord.<br>4.Teste os comandos no Discord:<br><br>Abra o Discord, vá até o servidor onde o bot foi adicionado e teste os comandos, como !ping ou qualquer outro que você tenha implementado.</p>
